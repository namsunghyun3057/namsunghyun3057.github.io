# [Robotics] D-H 파라미터와 좌표계 할당 규칙 (Craig)

로봇의 움직임을 수학적으로 계산하기 위해서는 각 관절과 뼈대에 좌표계(Frame)를 달고, 이를 수치화하는 과정이 필수적입니다. 지난 포스팅에 이어 이번 글에서는 로봇 기구학의 핵심인 **Denavit-Hartenberg (D-H) 파라미터**의 개념부터 실제 좌표계 할당 6단계, 그리고 3가지 실전 예시까지 완벽하게 정리해 보겠습니다.

---

## 1. Link Parameters(D-H Parameters)

로봇의 뼈대(Link)와 관절(Joint)은 총 4개의 파라미터로 완벽하게 묘사할 수 있습니다. 수식을 세울 때 가장 헷갈리기 쉬운 **$i$ 와 $i-1$ 의 차이점**을 먼저 확실히 잡고 가야 합니다.

<div align="center">
  <img src="/assets/img/robotics/robotics-5-2.png" alt="location-of-frame" style="width: 80%; max-width: 600px; display: block; margin: 0 auto;">
  <p><em>{i-1}과 {i}의 파라미터 정보</em></p>
</div>

  * **$i-1$ 그룹 (링크의 고유한 형태):** 이전 축($i-1$)과 현재 축($i$)을 이어주는 뼈대(Link) 자체의 특성입니다. 로봇을 만들 때 이미 고정되는 기구학적 형태를 나타냅니다.
  * **$i$ 그룹 (관절의 움직임 상태):** 현재 축($i$)에서 발생하는 관절(Joint)의 결합 상태나 회전/이동 값을 의미합니다. 로봇이 움직일 때 변하는 값들이 포함됩니다.

### 1.1. 파라미터 상세 정의

<div align="center">
  <img src="/assets/img/robotics/robotics-5-3.png" alt="DH-parameter" style="width: 100%; max-width: 600px; display: block; margin: 0 auto;">
  <p><em>DH parameter</em></p>
</div>

1.  **$a_{i-1}$ (링크 길이, Link Length):** $Z_{i-1}$ 축과 $Z_i$ 축 사이의 최단 거리입니다. ($X_{i-1}$ 축을 따라 측정)
2.  **$\alpha_{i-1}$ (링크 비틀림, Link Twist):** $Z_{i-1}$ 축에서 $Z_i$ 축으로 얼만큼 꼬여있는지 나타내는 각도입니다. ($X_{i-1}$ 축을 기준으로 회전)
3.  **$d_i$ (링크 오프셋, Link Offset):** $X_{i-1}$ 축과 $X_i$ 축 사이의 거리입니다. ($Z_i$ 축을 따라 측정하며, 직동 관절(Prismatic)의 구동 변수가 됩니다.)
4.  **$\theta_i$ (관절 각도, Joint Angle):** $X_{i-1}$ 축에서 $X_i$ 축으로 얼만큼 틀어져 있는지 나타내는 각도입니다. ($Z_i$ 축을 기준으로 회전하며, 회전 관절(Revolute)의 구동 변수가 됩니다.)

> **핵심 요약**  
> $a$와 $\alpha$는 **X축**을 기준으로 보고, $d$와 $\theta$는 **Z축**을 기준으로 봅니다\!

## 2. Link-Frame Attachment Procedure

좌표계를 내 마음대로 달면 수식이 꼬이고 변환 행렬을 제대로 세울 수 없습니다. 다음은 기구학에서 공식적으로 사용하는 프레임 부착 절차(Attachment Procedure) 6단계입니다.

1.  **관절 축 파악:** 각 관절이 회전하거나 직선 운동하는 고유의 축(가상의 무한한 선)을 식별합니다.
2.  **원점 지정:** $i$번째 축과 $i+1$번째 축 사이의 \*\*공통 수선(최단 거리 선)\*\*이 $i$번째 축과 만나는 지점을 프레임 $\{i\}$의 원점으로 잡습니다.
3.  **Z축 꽂기 ($Z_i$):** 방금 찾은 관절의 구동 축 방향 그대로 $Z_i$ 축을 지정합니다. (관절이 움직이는 뼈대 축)
4.  **X축 긋기 ($X_i$):** $i$번째 축에서 $i+1$번째 축을 향하는 **공통 수선 방향**을 $X_i$ 축으로 지정합니다. (두 Z축을 잇는 가장 짧은 다리)
5.  **Y축 완성 ($Y_i$):** Z축과 X축이 정해졌으므로, **오른손 법칙**을 사용하여 나머지 $Y_i$ 축을 세팅합니다.
6.  **베이스 $\{0\}$ 와 끝단 $\{N\}$ 예외 처리:** \* **베이스(프레임 $\{0\}$):** 첫 번째 관절 변수가 0일 때, 프레임 $\{0\}$이 프레임 $\{1\}$과 완벽하게 일치하도록 복사해서 붙입니다. (즉, $Z_0$와 $Z_1$은 일치합니다.)
      * **끝단(프레임 $\{N\}$):** 파라미터(특히 $a, \alpha, d$)가 최대한 0이 많이 나오도록 원점 위치와 $X_N$ 방향을 센스 있게 지정합니다.

## 3. 특수한 경우의 파라미터 찾기 (Special Cases)

현실의 로봇은 축들이 항상 떨어져 있지 않습니다. 축 긋기가 헷갈리는 두 가지 특수 상황을 알아봅시다.

### 3.1. 두 관절 축이 교차할 때 (Intersecting Axes)

  * **특징:** $Z_{i-1}$과 $Z_i$가 한 점에서 만나 십자가를 이룹니다.
  * **해결:** 두 축 사이의 거리가 0이므로 다리를 놓을 수 없습니다. 대신 두 Z축이 만드는 평면에 **수직(법선)인 방향**으로 $X_{i-1}$을 빼줍니다. (앞/뒤 두 방향 중 계산이 편하거나 전체 부호가 깔끔해지는 쪽을 임의로 선택합니다.)

### 3.2. 두 관절 축이 평행할 때 (Parallel Axes)

  * **특징:** $Z_{i-1}$과 $Z_i$가 평행합니다.
  * **해결:** 다리를 무한히 많이 놓을 수 있으므로 원점의 위치를 자유롭게 정할 수 있습니다.
  * **Tip:** 링크 오프셋 **$d_i = 0$이 되도록** 다음 관절의 원점과 일직선이 되는 곳에 현재의 원점을 잡는 것이 좋습니다. 파라미터 표에 0이 많아질수록 나중에 $4 \times 4$ 행렬을 곱할 때 연산이 훨씬 단순해집니다\!

## 4. 실전 예시 3가지와 D-H 파라미터 표

앞서 배운 규칙을 바탕으로 3가지 대표적인 메커니즘에 좌표계를 달고 파라미터를 뽑아보겠습니다.

### 4.1. 예시 1: 3축 평면 로봇 (3R Planar Manipulator)

<div align="center">
  <img src="/assets/img/robotics/robotics-5-4.png" alt="3r-planar-manipulator" style="width: 80%; max-width: 600px; display: block; margin: 0 auto;">
  <p><em>3R Planar Manipulator</em></p>
</div>

가장 기본적인 형태로, 3개의 회전 관절(Revolute)이 모두 하나의 2차원 평면 위에서 움직입니다.

  * **특징:** 모든 Z축($Z_0, Z_1, Z_2$)이 화면 밖으로 튀어나오는 방향으로 **나란히 평행**합니다.
  * **X축 긋기:** 축들이 평행하므로, 앞서 배운 꿀팁을 적용해 로봇의 물리적인 뼈대(링크)를 따라 쭉 일직선으로 $X_1, X_2$ 축을 긋습니다. 베이스인 $Z_0$는 $Z_1$과 일치시킵니다.

<div align="center">
  <img src="/assets/img/robotics/robotics-5-5.png" alt="3r-planar-manipulator" style="width: 80%; max-width: 600px; display: block; margin: 0 auto;">
  <p><em>3R Planar Manipulator 프레임 할당 예시</em></p>
</div>

| $i$ | $\alpha_{i-1}$ | $a_{i-1}$ | $d_i$ | $\theta_i$ |
| :---: | :---: | :---: | :---: | :---: |
| 1 | 0 | 0 | 0 | $\theta_1$ |
| 2 | 0 | $L_1$ | 0 | $\theta_2$ |
| 3 | 0 | $L_2$ | 0 | $\theta_3$ |

> *(모든 Z축이 평행하므로 비틀림 각도 $\alpha$는 모두 0이 되며, Z축 방향 이동이 없으므로 오프셋 $d$ 역시 0입니다.)*

### 4.2. 예시 2: 3자유도 로봇 (1개의 직동 관절 포함)

<div align="center">
  <img src="/assets/img/robotics/robotics-5-6.png" alt="3dof-prismatic-joint" style="width: 80%; max-width: 600px; display: block; margin: 0 auto;">
  <p><em>Prismatic Joint가 포함된 manipulator</em></p>
</div>

회전 관절 2개와 미끄럼 관절(Prismatic) 1개가 섞여 있는 구조입니다.

  * **특징:** 3번째 관절이 미끄럼 관절이므로 $\theta_3$는 고정값이 되고, 대신 $d_3$가 로봇이 움직일 때마다 변하는 \*\*구동 변수(Variable)\*\*가 됩니다.

<div align="center">
  <img src="/assets/img/robotics/robotics-5-7.png" alt="prismatic-joint-mix" style="width: 80%; max-width: 600px; display: block; margin: 0 auto;">
  <p><em>Prismatic Joint가 포함된 manipulator 프레임 할당 예시</em></p>
</div>

| $i$ | $\alpha_{i-1}$ | $a_{i-1}$ | $d_i$ | $\theta_i$ |
| :---: | :---: | :---: | :---: | :---: |
| 1 | 0 | 0 | 0 | $\theta_1$ |
| 2 | $90^\circ$ | 0 | $d_2$ (변수) | 0 |
| 3 | 0 | 0 | $L_2$ | $\theta_3$ |

> *($Z_0$에서 $Z_1$으로 갈 때 축이 꺾이므로 $\alpha_1=90^\circ$가 되며, 2번에서 3번으로는 방향 변화가 없으므로 $\alpha_2=0^\circ$입니다.)*

### 4.3. 예시 3: 1, 2번 축 교차 & 2, 3번 축 평행 (3R Non-planar) - 4가지 표현 방법  

<div align="center">
  <img src="/assets/img/robotics/robotics-5-8.png" alt="3r-non-planar" style="width: 80%; max-width: 600px; display: block; margin: 0 auto;">
  <p><em>교차하는 축과 평행한 축이 혼재된 3차원 매니퓰레이터 예시</em></p>
</div>

입체적으로 움직이는 다관절 로봇 팔의 가장 전형적인 어깨-팔꿈치 구조입니다. (페이지 28~30)
이 메커니즘은 D-H 파라미터를 설정할 때 **총 4가지의 서로 다른 (하지만 모두 정답인) 좌표계 할당**이 가능합니다. 그 이유는 다음과 같이 축의 방향을 선택할 자유도가 생기기 때문입니다.

1. **$X_1$ 축의 방향 (2가지):** $Z_0$와 $Z_1$이 한 점에서 **교차**하므로, 교차 평면에 수직인 $X_1$ 축을 화면 앞으로 튀어나오게 잡을 수도 있고, 뒤로 들어가게 잡을 수도 있습니다.
2. **$Z_2$ 축의 방향 (2가지):** $Z_1$과 $Z_2$가 **평행**하므로, $Z_2$ 축을 $Z_1$과 같은 방향으로 나란히 잡을 수도 있고, 반대 방향으로 180도 뒤집어서 잡을 수도 있습니다.

이 두 가지 선택의 $2 \times 2$ 조합을 통해 4개의 각기 다른 파라미터 표가 완성됩니다. 

#### 방법 1: $X_1$ 방향 선택에 따른 역방향 회전 ($\alpha_1 = -90^\circ, \theta_2 = -90^\circ$)
$X_1$ 축을 지정한 방향을 기준으로 오른손 법칙을 적용했을 때 회전 방향이 역방향(-)이 되는 케이스입니다.
* **$\alpha_1 = -90^\circ$ 인 이유:** $X_1$ 축을 엄지로 두었을 때, $Z_1$에서 $Z_2$로 향하는 회전이 손가락이 감기는 방향의 반대(역방향)로 90도 꺾이기 때문입니다.
* **$\theta_2 = -90^\circ$ 인 이유:** $Z_2$ 축을 엄지로 두었을 때, 기준이 되는 $X_1$에서 $X_2$로 향하는 회전 역시 손가락이 감기는 반시계(+) 방향의 반대인 시계 방향으로 90도 돌아가야 일치하기 때문입니다.

| $i$ | $\alpha_{i-1}$ | $a_{i-1}$ | $d_i$ | $\theta_i$ |
| :---: | :---: | :---: | :---: | :---: |
| 1 | $0^\circ$ | 0 | 0 | $\theta_1$ |
| 2 | $-90^\circ$ | 0 | 0 | $\theta_2 - 90^\circ$ |
| 3 | $0^\circ$ | $a_2$ | 0 | $\theta_3$ |

#### 방법 2: $X_1$ 방향 반대 선택 ($\alpha_1 = 90^\circ, \theta_2 = 90^\circ$)
방법 1에서 $X_1$ 축을 반대 방향으로 뻗게 지정한 경우입니다. 오른손 법칙에 따라 회전 부호가 모두 양수(+)로 바뀝니다.

| $i$ | $\alpha_{i-1}$ | $a_{i-1}$ | $d_i$ | $\theta_i$ |
| :---: | :---: | :---: | :---: | :---: |
| 1 | $0^\circ$ | 0 | 0 | $\theta_1$ |
| 2 | $90^\circ$ | 0 | 0 | $\theta_2 + 90^\circ$ |
| 3 | $0^\circ$ | $a_2$ | 0 | $\theta_3$ |

#### 방법 3: 방법 1에서 $Z_3$ 축 방향 뒤집기
방법 1의 상태에서 평행한 $Z_2$와 $Z_3$ 중 $Z_3$ 축의 방향을 180도 뒤집어 지정한 경우입니다.

| $i$ | $\alpha_{i-1}$ | $a_{i-1}$ | $d_i$ | $\theta_i$ |
| :---: | :---: | :---: | :---: | :---: |
| 1 | $0^\circ$ | 0 | 0 | $\theta_1$ |
| 2 | $-90^\circ$ | 0 | 0 | $\theta_2 - 90^\circ$ |
| 3 | $180^\circ$ | $a_2$ | 0 | $\theta_3$ |

#### 방법 4: 방법 2에서 $Z_3$ 축 방향 뒤집기
방법 2의 상태에서 $Z_3$ 축의 방향을 180도 뒤집어 지정한 경우입니다.

| $i$ | $\alpha_{i-1}$ | $a_{i-1}$ | $d_i$ | $\theta_i$ |
| :---: | :---: | :---: | :---: | :---: |
| 1 | $0^\circ$ | 0 | 0 | $\theta_1$ |
| 2 | $90^\circ$ | 0 | 0 | $\theta_2 + 90^\circ$ |
| 3 | $180^\circ$ | $a_2$ | 0 | $\theta_3$ |

> *(이 4가지 표 중 어떤 것을 선택해서 변환 행렬을 곱하더라도, 최종적으로 도출되는 로봇 끝단의 3차원 위치 수식 결과는 완벽하게 동일합니다!)*
